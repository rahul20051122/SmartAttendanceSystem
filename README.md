# 🎓 Smart Attendance System

A Flask-based Smart Attendance Management System that uses Face Recognition technology to automatically mark student attendance.

This project was developed as a Computer Science Engineering (CSE) project and demonstrates the integration of:

- Python
- Flask
- OpenCV
- SQLite
- Face Recognition
- Attendance Analytics
- Excel Reporting
- Email Notifications

---

# 🚀 Features

## 👨‍🎓 Student Management

- Register Students
- Store Student Details
- Unique Roll Number Validation
- Delete Students

---

## 📷 Face Dataset Collection

- Capture multiple face images using webcam
- Automatically create dataset folders
- Store images for model training

---

## 🧠 Face Recognition Training

- Train LBPH Face Recognition Model
- Generate trainer.yml automatically
- Support multiple students

---

## ✅ Smart Attendance Marking

- Detect and recognize registered students
- Automatically mark attendance
- Prevent duplicate attendance entries
- Store date and time

---

## 📊 Attendance Analytics

- Total Students
- Total Attendance Records
- Monthly Attendance Trends
- Attendance Percentage Analysis
- Top Performing Students
- Low Attendance Alerts

---

## 📧 Automatic Absent Student Notification

- Daily attendance monitoring
- Automatic email alerts for absent students
- Scheduled background execution

---

## 📁 Attendance Reports

- View Attendance Records
- Search Student Attendance
- Attendance History Dashboard

---

## 📤 Excel Export

- Export attendance records
- Generate Excel reports
- Easy sharing with faculty

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/rahul20051122/SmartAttendanceSystem.git
cd SmartAttendanceSystem
```

## Create Virtual Environment

```bash
python -m venv venv
```

## Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Application

```bash
python app.py
```

Open Browser:

```text
http://127.0.0.1:5000
```
