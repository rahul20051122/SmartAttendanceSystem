Hardware Checklist

Run through these steps if the camera hardware reports offline status:

  • Release Application Locks: Check taskbar and background services for Zoom, OBS, MS Teams, or Discord. Close programs locking video drivers.
  • System Permission Check: Under Windows Settings > Privacy & security > Camera, ensure "Allow desktop apps to access your camera" is enabled.
  • Index Fallback Cycle: The application auto-scans indices 0, 1, and 2. Virtual capture streams or virtual drivers may block access. Try disconnecting external webcams to reset indices.
  • Driver Calibration: Make sure your webcam driver is updated. Standard DirectShow interfaces require compliant OS frame encoders.
